# Platea Sur — Indumentaria Futbolera

Sitio web oficial de **Platea Sur**, catálogo digital e e-commerce para indumentaria de fútbol en Zona Sur. Diseñado y desarrollado con foco en velocidad, diseño neón futbolero y una experiencia de compra ágil mediante WhatsApp.

---

## ⚡ Características Principales

* **Catálogo interactivo**: Filtros por categoría sincronizados (`Todas`, `Liga Argentina`, `Ascenso Argentino`, `Retro / Clásicas`, `Niños`, `Shorts`, `Selecciones`) y ordenamiento por precio/nombre.
* **Carrito y Checkout a medida**:
  * Elección entre **Envío a domicilio** (dirección, localidad, código postal) o **Punto de encuentro Zona Sur** (desplegable con estaciones del Tren Roca).
  * Envío automático del pedido formateado directo a WhatsApp.
* **Panel de Administración**: Gestión interna protegida mediante PIN para actualizar catálogo, precios y stock.
* **Branding & Identidad**:
  * Isotipo vectorial e insignias personalizadas con la estética de la marca.
  * Marquesina informativa superior dinámica.
  * Interfaz optimizada para celulares y escritorio en modo oscuro (*Dark Mode*).

---

## 🛠️ Tecnologías Utilizadas

* **Frontend**: React, TypeScript, Vite.
* **Estilos & UI**: Tailwind CSS, Lucide Icons.
* **Estado Global**: Zustand.
* **Desarrollo & Branding**: Loomic Studio.

---

## 🚀 Inicio Rápido

### Requisitos previos
* Node.js (v18 o superior)
* npm

### Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```
